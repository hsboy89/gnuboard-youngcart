# PG사 결제 설정 가이드

## API 키 필요 여부

### 실제 결제를 사용하려면: **필수**
각 PG사에 가입하고 계약을 체결한 후 API 키를 발급받아야 합니다.

### 테스트/개발 목적이라면: **선택**
현재 구현된 코드는 API 키가 없어도 주문 플로우를 테스트할 수 있습니다.

---

## 각 PG사별 API 키 정보

### 1. NHN KCP
- **필요한 키**: 
  - `PG_KCP_SITE_CD`: 사이트 코드
  - `PG_KCP_SITE_KEY`: 사이트 키
- **가입/계약**: https://admin.kcp.co.kr/
- **수수료**: 신용카드 1.9%~3.4%
- **초기 등록비**: 22만원 (현재 무료 이벤트 진행 중)
- **테스트 모드**: API 키 없이도 주문 플로우 테스트 가능

### 2. KG이니시스
- **필요한 키**:
  - `PG_INICIS_MID`: 상점 ID (MID)
  - `PG_INICIS_KEY`: 상점 키
- **가입/계약**: https://www.inicis.com/
- **수수료**: PG사별 상이
- **테스트 모드**: API 키 없이도 주문 플로우 테스트 가능

### 3. 토스페이먼츠
- **필요한 키**:
  - `PG_TOSS_CLIENT_KEY`: 클라이언트 키 (공개 키)
  - `PG_TOSS_SECRET_KEY`: 시크릿 키 (비공개 키)
- **가입/계약**: https://www.tosspayments.com/
- **수수료**: PG사별 상이
- **테스트 모드**: API 키 없이도 주문 플로우 테스트 가능

---

## 현재 구현 상태

### API 키가 없는 경우
- 주문은 정상적으로 생성됩니다
- 결제 페이지에서 "테스트 모드" 메시지가 표시됩니다
- "테스트 완료" 버튼을 클릭하면 주문 완료 페이지로 이동합니다
- 실제 결제는 진행되지 않습니다

### API 키가 있는 경우
- 실제 PG사 결제 페이지로 이동합니다
- iframe으로 결제 페이지가 표시됩니다
- 결제 완료 후 자동으로 주문 완료 페이지로 이동합니다

---

## 설정 방법

### 1. API 키 발급 (실제 결제 사용 시)

각 PG사에 가입하고 계약을 체결한 후:
1. PG사 관리자 페이지에서 상점 정보 확인
2. API 키/인증 정보 발급
3. `payment/config.php` 파일에 입력

### 2. 테스트 모드 사용 (개발 목적)

API 키 없이도 테스트 가능:
1. `payment/config.php`의 API 키는 빈 값으로 유지
2. 주문하기 버튼 클릭
3. 결제 방법 선택 (KCP, 이니시스, 토스페이먼츠)
4. "테스트 완료" 버튼으로 주문 플로우 확인

## 권장 사항

### 개발 단계
- API 키 없이 주문 플로우 테스트
- 무통장입금으로 주문 생성 테스트

### 운영 준비 단계
- 원하는 PG사 선택 (1개 또는 여러 개)
- PG사와 계약 체결
- API 키 발급 및 설정
- 테스트 결제 진행
- 운영 환경 배포

### [ARCHITECTURE.md](./ARCHITECTURE.md)

- 시스템 아키텍처
- 디렉토리 구조
- 데이터베이스 스키마
- 핵심 기능
- 보안 고려사항

### [TECH_STACK.md](./TECH_STACK.md)
사용된 모든 기술 스택에 대한 상세 정보를 제공합니다.
- 백엔드 기술 (PHP, Gnuboard, YoungCart)
- 데이터베이스 (SQLite, PDO)
- 프론트엔드 기술 (HTML5, CSS3, JavaScript)
- 웹 서버
- 개발 도구

### [API.md](./API.md)
프로젝트에서 사용하는 주요 함수와 API를 설명합니다.
- 데이터베이스 함수
- 세션 함수
- 다국어 함수
- 인증 함수
- 쿼리 예시

### [PHP_TRENDS.md](./PHP_TRENDS.md)
PHP의 장단점, 과거와 현재의 사용 추세, 최신 웹 개발 트렌드와의 비교를 다룹니다.
- PHP의 장단점
- PHP 버전별 변화
- 최신 웹 개발 트렌드 비교
- 시장 점유율 및 사용 현황
- PHP의 미래 전망

### [FEATURES.md](./FEATURES.md)
프로젝트에서 실제로 사용된 Gnuboard 기능과 YoungCart 기능을 상세히 정리합니다.
- Gnuboard 기능 사용 현황 (회원 관리, 게시판, 파일 관리 등)
- YoungCart 기능 사용 현황 (상품 관리, 카테고리, 주문, 결제 등)
- 구현 상태 및 미구현 기능
- 파일별 기능 사용 현황

### [ORDER_SYSTEM.md](./ORDER_SYSTEM.md)
주문 및 결제 시스템에 대한 상세 정보를 제공합니다.
- 주문 프로세스
- 데이터베이스 스키마
- 자동 테이블 생성
- 재고 관리
- 결제 방법 (무통장입금, KCP, 이니시스, 토스페이먼츠)
- 테스트 방법

### [ADMIN_PANEL.md](./ADMIN_PANEL.md)
관리자 GUI 기반 데이터 관리 시스템에 대한 상세 정보를 제공합니다.
- 접근 권한
- 관리 가능한 데이터 (회원, 게시판, 게시글, 상품, 카테고리)

- 보안 고려사항

### [PAYMENT_SETUP.md](./PAYMENT_SETUP.md)

- 테스트 모드 사용법
- 비용 정보

### [DATA_ACCESS.md](./DATA_ACCESS.md)
데이터를 조회하는 다양한 방법을 설명합니다.

- 유용한 쿼리 예시
